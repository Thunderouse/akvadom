# АкваДом — центр климатического комфорта

Одностраничный сайт вымышленной услуги: выездная диагностика влажности, защита от протечек, автоматический полив, водоотведение и сбор дождевой воды для жителей Сочи.

Учебная работа по дисциплине «Деловые коммуникации в профессиональной деятельности».

## Что внутри

Один файл `index.html` без сборки и внешних зависимостей: стили, SVG-иконки и скрипты встроены. Открывается двойным щелчком.

- первый экран с «паспортом микроклимата» — пример отчёта с замерами;
- блок симптомов, состав диагностики, четыре продуктовых решения;
- калькулятор бюджета (тип объекта + набор работ, цены для Сочи);
- тарифы: диагностика, «Комфорт», участок под ключ, обслуживание;
- кейсы с цифрами, этапы работы, отзывы, FAQ;
- форма заявки с маской телефона, валидацией и согласием по 152-ФЗ;
- адаптив: контрольные точки 1000 / 680 / 560 px, проверено на 375 px без горизонтальной прокрутки.

Форма работает в демонстрационном режиме: заявка не уходит на сервер, показывается сообщение об успехе.

## Публикация

Сайт отдаётся GitHub Pages из ветки `main`: https://thunderouse.github.io/akvadom/

## Цены

Расчётные, сверены с открытыми прайсами подрядчиков Сочи и Адлеровского района (дренаж, автополив, защита от протечек). Подробное обоснование — в пояснительной записке к работе.
